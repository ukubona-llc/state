2. The Ensemble Disagreement Gate

A single local model, run once, cannot distinguish "this zone is genuinely underdetermined" from "this rollout happened to hallucinate." Nodes IV and V have no Federated Ground Truth to check error against, unlike I–III. The fix is to replace ground-truth comparison with cross-sample and cross-model agreement — the same signal, produced a different way.

Step 1 · Sample
Run the same prompt 3–5 times at temperature on the local model, or against a second small local model. No single rollout is trusted in isolation.
Step 2 · Measure Agreement
Score agreement across the samples. Convergence on a claim behaves like an overdetermined answer even off the Taylor-expansion manifold. Scatter is the underdetermined-zone signal — the runtime classifier the ontology needed but didn't have.
Step 3 · Gate
Disagreement-as-gate stands in for the eigengap check at nodes IV–V, where $g$ itself can't be computed against ground truth. The diagnostic and the runtime classifier are the same object.

3. The Constraint: Grammar-Constrained Decoding

Since SlowAPI runs local inference, the lever isn't a cloud tool-call contract — it's a decoding-time constraint. A GBNF grammar or equivalent JSON-schema constraint makes free-text narration structurally unreachable, not merely discouraged. The model must either commit to a resolve event or confess ambiguity through a required field — never drift into prose instead. 

from pydantic import BaseModel
from typing import Literal, Union

class LedgerEvent(BaseModel):
    mode: Literal["resolve"] = "resolve"
    event_type: str                  # e.g. "eigenmode.identity_resolved"
    payload: dict
    manifold_zone: Literal["overdetermined", "underdetermined"]
    confidence: float                 # from ensemble agreement, not vibes
    provenance: str                   # e.g. "slowapi:gemma-4-31b-qat"

class ElicitationRequest(BaseModel):
    mode: Literal["elicit"] = "elicit"
    question: str
    options: list[str] | None = None

SlowAPIResponse = Union[LedgerEvent, ElicitationRequest]
